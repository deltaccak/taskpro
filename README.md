# TasKPro - Gestor de Tareas Personal
Aplicación web para anotar tareas de todo tipo (trabajo, estudio, personales, etc.), organizarlas por prioridad o categoría, y marcarlas como completadas.  
Incluye temas claro y oscuro para adaptarse a tu estilo de trabajo y preferencias visuales.

## Contenido de la aplicación

### Dashboard de estadísticas
- Panel de métricas en tiempo real con total de tareas creadas.
- Contador de tareas completadas y pendientes por realizar.
- Tasa de finalización calculada automáticamente.
- Barra de progreso visual para seguimiento del avance general.

### Gestión de tareas
- Creación rápida de tareas con título, descripción y categoría.
- Sistema de prioridades (baja, media, alta) con codificación visual.
- Fechas límite para organizar plazos y vencimientos.
- Edición completa de tareas existentes mediante modal interactivo.

### Organización y filtrado
- Filtros inteligentes por estado: todas, pendientes y completadas.
- Categorización automática: personal, trabajo, estudio, hogar y otros.
- Buscador de tareas por título o contenido.
- Marcado rápido de completado con actualización instantánea.

### Interfaz y experiencia
- Diseño responsivo optimizado para dispositivos móviles y escritorio.
- Modo claro y oscuro intercambiable según preferencias del usuario.
- Iconografía intuitiva con Font Awesome para mejor comprensión visual.
- Animaciones suaves y transiciones fluidas para una experiencia moderna.
